# E3 on Kaggle

Attach [BraTS21](https://www.kaggle.com/datasets/dschettler8845/brats-2021-task1) and the [frozen ANDi checkpoint](https://www.kaggle.com/models/ahmadabbas176/232-ema-ckpt-pt/PyTorch/default/1). Select **GPU T4 ×2**, enable **Internet**, and select **Save Version → Save & Run All** with the following cell.

```python
import subprocess
import sys
from pathlib import Path
from tempfile import TemporaryDirectory

SMOKE = True
BRANCH = "codex/stack-05-e3"
LJUBLJANA_ROOT = None

with TemporaryDirectory() as work:
    repo = Path(work) / "ANDi"
    subprocess.run(
        ["git", "clone", "--single-branch", "--branch", BRANCH,
         "https://github.com/ahmad-m-abbas/ANDi.git", str(repo)],
        check=True,
    )
    command = [sys.executable, "-u", "kaggle/e3_one_cell.py"]
    if SMOKE:
        command.append("--smoke")
    if LJUBLJANA_ROOT:
        command.extend(("--ljubljana", LJUBLJANA_ROOT))
    subprocess.run(command, cwd=repo, check=True)
```

The smoke test fits on two BraTS21 validation subjects and evaluates two other validation subjects. It runs all 125 timesteps and five scoring methods, then writes `/kaggle/working/andi-e3-smoke/report.md`. Look for `E3 smoke complete` in the logs.

Set `SMOKE = False` and submit a new saved version for the full experiment. The reference uses the first 16 subjects in the BraTS21 validation list. The next eight provide residual diagnostics and a validation comparison. The runner freezes the reference before computing maps for all 251 held-out BraTS21 test subjects.

The reference samples at most 2,048 foreground voxels per subject, outside the lesion and its three-voxel dilation. Each timestep and modality has its own mean, standard deviation, median and scaled MAD. The runner compares the original ANDi geometric aggregation with four calibrated scores using the positive part or softplus of standardized log residuals. It measures pooled AUPRC, mean Yen+dilation Dice and false-positive rate in nonlesion foreground at median filter sizes 0, 3 and 5. The values describe a reference drawn from nonlesion tissue in tumor-bearing scans.

The report and machine-readable results go to `/kaggle/working/andi-e3-full` with the reference parameters, counts, residual histograms and false-positive illustration. The saved version should include all of those files. The inference maps are scratch files.

For transfer, mount a prepared Ljubljana dataset and set `LJUBLJANA_ROOT` to the folder containing the `ljubljana_dev_out_*` patient folders. Each patient folder uses the registered ANDi filename convention with `<patient-number>_flair.nii.gz`, `_t1.nii.gz`, `_t1ce.nii.gz`, `_t2.nii.gz`, and `_seg.nii.gz`. The transfer uses the same frozen BraTS21 reference and the 25 subjects in the checked-in Ljubljana split.
